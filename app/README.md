# Curio — a universal collection app

Curio is a cross-platform (Android + iOS) Flutter app for building personal
collections. Swipe through decks of **attractions, cities, movies and books**
and decide on each one:

- **Skip** (swipe left) — not for you
- **Save** (swipe right) — add to your wishlist / watchlist / to-read
- **Done** (swipe up) — mark as visited / watched / read

Everything is stored **locally on the device** (no account, works offline).
Catalogs are pulled from public APIs where a key is provided, and fall back to
bundled sample data otherwise — so the app is fully usable the moment you run it.

## Architecture

```
lib/
├── main.dart                  # Hive init + Riverpod ProviderScope
├── app.dart                   # MaterialApp + theming
├── core/
│   ├── collections.dart       # CollectionType enum + per-type config/vocabulary
│   ├── api_config.dart        # API keys from --dart-define (all optional)
│   └── theme.dart             # Material 3 light/dark themes
├── data/
│   ├── models/                # CollectionItem, ItemStatus, SavedRecord
│   ├── sources/               # One ItemSource per API + SeedSource fallback
│   └── repositories/          # CatalogRepository (fetch), LibraryRepository (Hive)
├── state/providers.dart       # Riverpod providers + LibraryController
├── features/
│   ├── shell/                 # Bottom-nav scaffold
│   ├── discover/              # Swipe deck (flutter_card_swiper)
│   ├── library/               # Saved / done / skipped lists
│   └── detail/                # Item detail bottom sheet
└── widgets/                   # Shared UI (image with placeholder, chips)
assets/seed/                   # Offline sample data, one file per collection
```

**Adding a new collection** is a localized change: add a value to
`CollectionType` with its config in `core/collections.dart`, add an
`ItemSource` in `data/sources/`, wire it into `CatalogRepository`, and drop a
`assets/seed/<type>.json` file.

- **State:** Riverpod (no code generation)
- **Storage:** Hive (local, offline; records stored as plain JSON)
- **Networking:** `http`
- **Swipe UI:** `flutter_card_swiper`

## Getting started

This directory contains the Dart source, assets and tests. The native
platform folders (`android/`, `ios/`, `web/`) are generated by Flutter and are
**not** checked in, so generate them once after cloning:

```bash
cd app

# Generates android/ios/web scaffolding WITHOUT touching lib/ or pubspec.yaml
flutter create .

flutter pub get
flutter run
```

> **Android note:** for release builds to reach the network, ensure
> `android/app/src/main/AndroidManifest.xml` contains
> `<uses-permission android:name="android.permission.INTERNET"/>`.
> (Debug/profile builds already include it.)

### API keys (all optional)

Without keys the app runs on bundled sample data. Add keys via `--dart-define`
to switch a collection to live data (shown by a **LIVE** badge in the app):

```bash
flutter run \
  --dart-define=TMDB_API_KEY=your_tmdb_v3_key \
  --dart-define=OPENTRIPMAP_API_KEY=your_opentripmap_key \
  --dart-define=API_NINJAS_KEY=your_api_ninjas_key
  # Google Books needs no key; GOOGLE_BOOKS_API_KEY only raises rate limits
```

| Collection  | Source                         | Key required |
|-------------|--------------------------------|--------------|
| Movies      | TMDB                           | Yes          |
| Books       | Google Books                   | No           |
| Attractions | OpenTripMap                    | Yes          |
| Cities      | API Ninjas                     | Yes          |

- TMDB: https://www.themoviedb.org/settings/api
- OpenTripMap: https://opentripmap.io/product
- API Ninjas: https://api-ninjas.com/
